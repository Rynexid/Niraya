# Niraya POS - Tech Stack

## Frontend
- **Framework**: React 19 + TypeScript 7
- **Build Tool**: Vite 8
- **Routing**: React Router DOM 7
- **Styling**: Tailwind CSS v4 + tw-animate-css
- **UI Components**: shadcn/ui (new-york style, neutral base, CSS variables)
- **Icons**: Lucide React
- **State Management**: Zustand
- **Data Fetching**: TanStack Query
- **Forms**: React Hook Form + Zod + @hookform/resolvers
- **Tables**: TanStack Table
- **Charts**: Recharts
- **Notifications**: Sonner
- **Date Utilities**: date-fns
- **Theme**: next-themes
- **Utilities**: cmdk, vaul, input-otp, react-resizable-panels, class-variance-authority, clsx, tailwind-merge

## Backend
- **Runtime**: Bun
- **Framework**: Hono
- **Database**: PostgreSQL
- **ORM**: Drizzle ORM + drizzle-kit
- **Authentication**: Better Auth (email/password enabled)
- **Validation**: Zod

## Tooling
- **Package Manager**: Bun (workspaces)
- **Linting**: Oxlint
- **Type Checking**: TypeScript
